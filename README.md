# Lichtcontrole
Een slim IoT-systeem dat twee kelderlampen bewaakt via LDR-sensoren en een ESP32-C3-zender op batterijen. De gegevens (status, tijd, batterijniveau) worden via wifi opgeslagen in een beveiligde Firebase-database. Twee fysieke ontvangers en een GitHub Pages-webdashboard tonen realtime de lampstatus en waarschuwingen.
